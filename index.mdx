The Morabaa Public API lets your integration search products and create and retrieve orders for one business. Every API key belongs to one business and grants an explicit set of permissions.

## What you can build

- Product catalog synchronization
- Product availability and price lookups
- Order creation from a partner application
- Order status and history views for orders created by your API key

## Access boundaries

An API key can access only its assigned business. Order endpoints impose a narrower boundary: your key can retrieve only orders created through that same key. It cannot retrieve storefront orders or orders created by another key for the business.

<Info>
  Ask your Morabaa contact for an API key with the scopes your integration needs. The complete key is shown only when staff create or rotate it.
</Info>

## API conventions

| Convention | Behavior |
| --- | --- |
| Base path | All partner routes begin with `/external/v1` |
| Authentication | Send your key in `X-Api-Key` or `Authorization` |
| Pagination | List endpoints return 25 items per page |
| Errors | Failures return an `error` code and a human-readable `message` |
| Rate limits | Each key has a requests-per-minute limit |
